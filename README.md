# بوت تقييم الأوتاكو 🎌

بوت تليجرام يعطي المستخدم **50 سؤالًا** بأربعة اختيارات مرتبة من الأسهل للأصعب (10 مستويات × 5 أسئلة)،
ثم يقيّمه **من 10** ويمنحه لقبًا (حتى **ملك الأوتاكو 👑**) مع بطاقة نتيجة قابلة للمشاركة.

## التشغيل

```bash
pip install -r requirements.txt

python -m otaku_bot --check      # فحص بنك الأسئلة (بدون توكن)
python -m pytest -q              # الاختبارات (بدون توكن، تشمل محاكاة البوت كاملًا)

cp .env.example .env             # ضع BOT_TOKEN من @BotFather
python -m otaku_bot              # تشغيل البوت
```

## النشر بـ Docker
```bash
echo "BOT_TOKEN=التوكن_هنا" > .env
docker compose up -d --build     # يعيد التشغيل تلقائيًا، وقاعدة البيانات في volume دائم
docker compose logs -f bot
```
أو بدون compose: `docker build -t otaku-bot . && docker run -d --restart unless-stopped --env-file .env -v otaku-data:/data otaku-bot`.
التوكن لا يدخل الصورة أبدًا (يُمرَّر وقت التشغيل). على Railway/Fly.io ضع `BOT_TOKEN` في متغيرات البيئة وأضف volume على `/data`.

## كيف يعمل

| الملف | الدور |
|---|---|
| `data/questions.json` | بنك الأسئلة (مولَّد من `tools/build_questions.py`) |
| `otaku_bot/quiz.py` | المنطق الصافي: اختيار الأسئلة، معايرة الصعوبة، التقييم، الألقاب |
| `otaku_bot/db.py` | SQLite: أسئلة، مستخدمون، جلسات، ما رآه كل مستخدم |
| `otaku_bot/bot.py` | أوامر وأزرار تليجرام (aiogram 3) |
| `otaku_bot/card.py` | بطاقة النتيجة (Pillow) |

**اختيار الأسئلة:** 5 أسئلة من كل مستوى صعوبة، عشوائيًا، مع استبعاد ما رآه المستخدم من قبل
(عند النفاد يبدأ بالأقدم مشاهدة، وإن نفد مستوى يستعير من المجاور). تُخلط الخيارات في كل مرة ويُمنع تتالي نفس التصنيف.

**معايرة الصعوبة تلقائيًا:** كل سؤال له صعوبة أساسية (1–10) من تقديرك، وبعد كل إجابة تتحدث إحصائياته:

```
صعوبة_نهائية = (20 × الأساسية + عدد_الإجابات × ((1 − نسبة_الصحيح) × 10)) / (20 + عدد_الإجابات)
```
السؤال الذي يجيبه الجميع ينزل لمستوى أسهل تلقائيًا، والذي يفشل فيه الجميع يصعد.

**التقييم:** `10 × مجموع أوزان الإجابات الصحيحة / مجموع كل الأوزان` (وزن السؤال = مستواه).

| التقييم | اللقب |
|---|---|
| 0–2 | نوب / ما شفت أنمي |
| 2–4 | مشاهد عادي |
| 4–6 | أوتاكو |
| 6–8 | أوتاكو متمرس |
| 8–9.5 | سينسي |
| 9.5–10 | **ملك الأوتاكو 👑** |

## الاشتراك الإجباري
البوت يطلب الاشتراك في **@Anime1Galaxy** قبل بدء أي اختبار (أو استكماله) ويعرض زر «اشترك» وزر «تحققت».
**مهم:** لازم تضيف البوت **أدمن** في القناة (صلاحية عادية تكفي). إن لم يقدر البوت على التحقق فإنه **يرفض** ويقول
«تعذّر التحقق» بدل ما يفتح الباب للجميع. مالك القناة والمشرفون يُعدّون مشتركين فلن يُطلب منهم الاشتراك؛ جرّب بحساب آخر.
أمر `/diag` يعرض حالة البوت وحالتك في القناة لتشخيص أي مشكلة. لتغيير القناة أو التعطيل: `REQUIRED_CHANNEL=` في `.env` (فارغ = تعطيل).

## الأوامر
`/start` · `/retry` · `/stats` · `/top` · `/help` · `/flagged` (للأدمن: أسئلة نسبة نجاحها ≤ 27% وغالبًا فيها خطأ)

الحماية: الأزرار مربوطة بصاحب الجلسة والسؤال الحالي فقط، الإجابة تُسجَّل مرة واحدة، المؤقت يُفحص من جهة السيرفر،
فترة انتظار بين الاختبارات، والنتائج التي أغلب إجاباتها أسرع من ثانية لا ترفع أفضل نتيجة في المتصدرين.

## إضافة أسئلة
أضف أسطرًا في `tools/build_questions.py` بالصيغة
`(التصنيف, الصعوبة 1-10, السؤال, الجواب الصحيح, خطأ1, خطأ2, خطأ3)` ثم:

```bash
python tools/build_questions.py && python -m otaku_bot --check
```
عند إعادة تشغيل البوت تُحدَّث الأسئلة مع **الاحتفاظ بإحصائيات** الصعوبة الحقيقية (يعتمد على ثبات `id`، فأضف في آخر القائمة لا في المنتصف).

> ⚠️ البنك الحالي **308 أسئلة** (بداية للتجربة). لتقليل التكرار بين المحاولات تحتاج **40+ سؤالًا لكل مستوى**
> (400+ إجمالًا)، وأقل المستويات حاليًا هو الأول (19 سؤالًا). راجع الأسئلة بنفسك قبل الإطلاق: خطأ معلومة واحد يضر مصداقية البوت.
